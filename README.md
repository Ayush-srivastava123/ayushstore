# AyushStore 🩺

A modern full-stack medical online store built with React, Node.js, Express and MongoDB.

## Features
- Responsive medical e-commerce UI
- Product search and category filtering
- Product cards with pricing and stock status
- Shopping cart with quantity controls
- Simple checkout flow
- REST API-ready Express backend
- MongoDB-ready product and order architecture
- Environment variable support

## Stack
**Frontend:** React + Vite + CSS  
**Backend:** Node.js + Express  
**Database:** MongoDB

## Run locally

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```

Create `backend/.env` from `.env.example` and add your MongoDB connection string when connecting the database.

> This project is a software demo. Real-world medicine sales require appropriate licensing, prescription controls, pharmacist review, and compliance with applicable laws and regulations.
